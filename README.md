## Objetivo

Desenvolver uma aplicação capaz de representar uma casa inteligente com:

- Cômodos;
- Sensores;
- Atuadores;
- Monitoramento de temperatura;
- Detecção de fumaça;
- Acionamento de ar-condicionado;
- Acionamento de sirene;
- Persistência de objetos;
- Interface gráfica;
- Registro dos eventos da simulação.

## Organização do trabalho

A aplicação será composta por dois programas:

- **P1:** lê os dados iniciais de um arquivo CSV, cria os objetos da casa e salva esses objetos em formato binário.
- **P2:** restaura os objetos salvos, apresenta a interface gráfica, executa a simulação e registra os resultados.
